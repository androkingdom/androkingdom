### Projects

**Relay** (formerly PostHTML) · [web](https://posthtml.vercel.app) · [repo](https://github.com/androdotdev/plantodo) · [npm](https://www.npmjs.com/package/@androff/posthtml-cli)
Static HTML hosting platform for developers and AI agents. Upload HTML through the CLI, API, or MCP and get a short URL back. Server-side rendering, `{{placeholder}}` template interpolation, private post capability tokens, Postgres backend. The MCP server is what lets agents like Claude publish pages directly instead of just describing them.

**lyceum** · [repo](https://github.com/androdotdev/tutor) · [npm](https://www.npmjs.com/package/@androff/tutor-ai)
Terminal-first Socratic coding tutor running a multi-agent LLM pipeline. Built on `pi-agent-core` with a `pi-tui` terminal layer — asks questions instead of handing over answers, so you actually learn the material.

**cardfoi** · [live](https://cardfoi.vercel.app) · [repo](https://github.com/androdotdev/cardfoi)
Session-owned developer profile cards. Eight visual templates, work history entries, Cloudinary media uploads, capability-token sharing. No account required to view — built for the AI-native portfolio workflow.

**json-flow** · [live](https://json-flow-client.vercel.app) · [engine](https://www.npmjs.com/package/@andro.dev/jsonflow-engine) · [repo](https://github.com/androdotdev/json-flow)
Schema-first JSON diagram engine, not a JSON viewer. Zod-validated graph compiler that turns structured data into interactive flow, sequence, and graph diagrams. Renderer-agnostic (Cytoscape by default), fully typed, published as a standalone npm package.

**votesys** · [demo](https://votesys.vercel.app)
Online voting system MVP. Anonymous ballots, admin election management, auto-close, role-based access. Next.js + Drizzle + Better Auth.
